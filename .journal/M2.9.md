# M2.9 — SDK monorepo restructure + benchmark CI parity (pre-`v1.0-rc-sdk`)

**Branch:** `feature/sdk-restructure-rc` (off `main@4fa4ae0`)
**ADRs:** 0022 (restructure/rename/bench parity), 0023 (contract dir rename / M0-freeze amendment)

## What I did

Restructured the whole repo ahead of the first SDK release candidate:

1. **`sdk/` umbrella** — `git mv` the five flat modules into `sdk/java/{core,spring-adapter,benchmark}`
   and `sdk/python/{core,benchmark}`. Kept Gradle project names **flat** (only `projectDir`
   remaps) — this was the pivotal call: nested coordinates (`:sdk:java:core`) would have forced
   editing `project(":beacon-sdk-java")` inside the M0-frozen `contract/conformance/java/build.gradle.kts`.
   Flat names deliver the identical on-disk tree at zero freeze contact.
2. **Renamed the Spring module** `:beacon-spring-boot-starter` → `:beacon-sdk-spring-adapter`
   (adapter family). Verified runtime-safe: Spring auto-config is discovered via the
   `AutoConfiguration.imports` file, not the artifact name.
3. **Promoted the Python benchmark** out of the SDK into a sibling `sdk/python/benchmark/` with its
   own uv project (path-dep on `../core`), plus `BEACON_BENCH_*` env knobs for a CI smoke profile.
4. **Bench CI parity** — new `python-bench-nightly.yml` + a PR-time smoke step in `python-sdk.yml`,
   mirroring `jmh-nightly.yml` + `:compileJmhJava`.
5. **Renamed the contract dir** `beacon-s0-contract/` → `contract/` (user-requested), with ADR-0023
   amending the M0 freeze. Updated every functional path ref in both SDKs, the drift tool, build,
   and CI; left historical docs with a forward-note.
6. Docs/ADRs/CHANGELOG/CLAUDE.md updated; five atomic commits.

## Problems I faced

- **Path-resolution regressions the move surfaced.** Two Java contract tests hardcoded a
  single-level `..` to reach the contract; after the move to `sdk/java/core` (3 deep) they broke.
  Fixed with a depth-robust repo-root walk-up (search up for the `contract/` marker) rather than
  just adding `..`s. The drift tool similarly hardcoded `beacon-sdk-{java,python}/src/…` — caught
  only by *running* `--sdk all` after the move (a good argument for always exercising tooling, not
  just the build).
- **Latent PyYAML runtime-dep bug.** The sibling benchmark's runtime-only closure exposed that
  `config/_keys.py` imports `yaml` on the `import beacon.config` path while PyYAML was dev-only —
  a real runtime-only-install break, invisible while everything ran from the dev env. Moved it to
  runtime deps. This is exactly the value of the benchmark-as-separate-module: it's the first
  consumer that installs *only* the declared runtime closure.
- **zsh, twice.** `for f in $FILES` doesn't word-split in zsh, so my first two sed sweeps fed the
  whole file list to sed as one arg (and one even ran `git mv` mid-way, leaving an inconsistent
  tree). Recovered, then switched to `xargs` / `printf | while read`. Lesson logged.
- **Spotless** flagged a reflowed javadoc line after the string substitution; `spotlessApply` fixed it.

## What could have been done better

- I should have run the **drift tool** and a **runtime-only import** check right after commit 1/2,
  not at the contract-rename step — both regressions predate the rename and would have been caught
  a commit or two earlier.
- The two zsh word-split failures were avoidable; I know this shell. Used `xargs`/`while read` from
  then on.
- Broader doc path-modernization (some `beacon-sdk-*` *prose* mentions in older roadmap sections)
  was scoped down to functional refs + the authoritative CLAUDE.md layout; acceptable, but a fuller
  sweep could follow.

## Journal

The restructure itself was mechanical; the value was in what it *surfaced* — a real runtime-dep
bug and two stale path resolutions that the flat, from-dev-env layout had been hiding. Keeping
Gradle names flat while moving directories was the key insight that let a big-looking move stay
freeze-clean. The contract rename was the riskiest part (frozen module); resolving it to a clean
"content byte-identical, references updated, history not rewritten" story via ADR-0023 kept it honest.
